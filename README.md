# Second Brain Commands

> **Tri-Platform Agent Skill** for Claude Desktop / Code, Grok CLI, and Google Antigravity / Gemini.  
> Multi-Platform Slash Commands and Operational Protocol — Standardized slash commands and operational protocol for Second Brain MCP across all AI apps (Claude, Grok, Antigravity/Gemini, Cursor) enforcing pre-edit approval.

---

## Overview

`second-brain-commands` provides standardized capabilities across conversational AI platforms:
- Universal slash command catalog and syntax parser.
- Mandatory pre-edit approval policy enforcement rules and templates.
- Cross-platform operational triggers for memory retrieval and mutation.
- Direct command authorization vs agent-initiated write protocol.
- Tri-platform NTFS junctions connecting Claude, Grok, and Antigravity.
- Standard documentation suite: SKILL.md, HOW_TO_USE.txt, IMPLEMENTATION_PLAN.md, and README.md.

---

## Tri-Platform Architecture

Zero duplicate code across platforms. Canonical source resides in `.agents`:
- **Canonical Source**: `C:\Users\<you>\.agents\skills\second-brain-commands`
- **Claude**: `C:\Users\<you>\.claude\skills\second-brain-commands` (NTFS Junction)
- **Grok**: `C:\Users\<you>\.grok\skills\second-brain-commands` (NTFS Junction)
- **Antigravity**: `C:\Users\<you>\.gemini\config\skills\second-brain-commands` (NTFS Junction)
